# Kupala Hub — направления дизайна

Откройте `index.html` обычным двойным щелчком. Сервер и установка зависимостей не нужны.

- `a.html` — Ясный день: повестка и выбранные задачи.
- `b.html` — Планировщик: задачи рядом с календарём трёх дней.
- `c.html` — Кампус: верхняя навигация и выразительная главная.
- `a.png`, `b.png`, `c.png` — изображения вариантов при ширине 1440 px.
- `findings.md` — исследование, ограничения и аргументы выбора.
- `references/` — изображения референсов с официальных страниц; атрибуция в SOURCES.md.

Эскизы предназначены для выбора композиции десктопного веб-приложения. Внутренние кнопки и поля пока не работают; переключение вариантов сверху работает. Данные вымышленные, к университету не подключены. Мобильная версия не прорабатывалась.

Шрифт Onest загружается из Google Fonts; без сети используется Arial. Изображения PNG сохраняют показанный внешний вид. Предыдущий интерактивный макет находится отдельно в `../preview/index.html`. В архиве дизайн-исследования он не включён.

Проверено визуально в виртуальном Playwright при ширине 1440 px; дополнительно проверены горизонтальное переполнение при 1280 px и ссылки между вариантами. Пользовательские тесты со студентами не проводились.
