# Kupala Hub — дизайн-прототип v1

Статус: ожидает просмотра и утверждения пользователем. Это отдельный макет, а не реализация приложения.

Откройте `index.html` обычным браузером двойным щелчком. Сервер и установка зависимостей не нужны. Шрифт Onest загружается из Google Fonts; при отсутствии сети используется Arial.

Четыре экрана: Сегодня, Расписание, Задачи, Ассистент. Десктоп от 1120 px, основной просмотр — 1440 px. Адаптация для телефона по просьбе пользователя отложена.

Доступны переходы, день/неделя, карточка пары, уведомления, создание и редактирование задачи, отметка выполнения, поиск и фильтры задач, пример диалога, подтверждение предложенной задачи и переключение темы. Данные демонстрационные; изменения сбрасываются при перезагрузке. API, модель, аккаунты и экспорт календаря не подключены. Кнопки недоступных сценариев объясняют ограничение.

Направление: спокойный светлый интерфейс с зелёными акцентами, глубокая зелёная карточка текущей пары, мягкий оранжевый для изменений и дедлайнов. Постоянное боковое меню; на главной — события дня слева, ближайшие задачи и подсказка справа. Остальные страницы используют ту же типографику, интервалы и контролы.

Изображения: `today.png`, `schedule.png`, `tasks.png`, `assistant.png`, `assistant-dark.png`.

После утверждения визуального дизайна можно переходить к реализации. До этого макет служит для обсуждения и изменений.
