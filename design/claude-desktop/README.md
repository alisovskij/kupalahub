# Kupala Hub — десктоп

Источник: https://claude.ai/artifact/GBadpkRVNCLvuDnhfAGr94#page-dcb81aee8d83
Сохранено: 15 ноября 2026 года (Europe/Moscow).

## Что сохранено

- `source/`: 22 оригинальных HTML-файла экранов и компонентов со встроенными стилями и логикой прототипа.
- `source/canvas.json`: названия, порядок, размеры и расположение экранов на холсте.
- `files.json`: опубликованный манифест с размерами и SHA-256. Он также перечисляет служебные файлы платформы Claude, которые в эту копию не входят.

Все 23 файла в `source/` побайтово совпадают с SHA-256 опубликованного манифеста. Исходники сохранены без изменений.

## Структура макета

Основные экраны: «Сегодня», два состояния расписания и выбор группы при входе.
Учёба: оценки с интерактивным сценарием «Что если?», задания, сессия, тест по базам данных.
Ассистент: план подготовки к сессии и подбор места для самостоятельной работы.
Справочники: свободные аудитории и преподаватели.
Настройки и окна: уведомления, поиск, маршрут, новая задача, письмо преподавателю, демо-режим и вход по логину портала.
Общие компоненты: боковое меню и верхняя панель.

Основной размер экранов — 1440 × 920 px; боковое меню — 248 × 900 px; верхняя панель — 1192 × 72 px.

## Визуальная система

Светлый фон #F3F5F8, белые карточки, основной текст #15171C.
Основной зелёный #0C6E5F, оранжевый акцент #FF6A3D.
Шрифты: Onest для интерфейса, Unbounded для заголовков, JetBrains Mono для времени и чисел.
Карточки со скруглением 16 px, крупный блок текущей пары — 20 px, кнопки — 12 px.
На главной странице: боковая навигация, верхняя панель, текущая и следующая пары, шкала дня, изменения расписания, свободное окно, ассистент и задачи.

## Ограничения локальной копии

Это исходники прототипа в формате среды Claude: используются `x-dc`, `helmet`, `dc-import`, шаблоны `{{…}}`, скрипты `text/x-dc` и ссылка на `support.js`. Последний отсутствует в опубликованном манифесте. Поэтому открытие HTML обычным браузером не воспроизводит весь прототип: для самостоятельного просмотра нужна среда исполнения или конвертация в обычный HTML/приложение. Шрифты подключаются через Google Fonts.

В макете расписание обозначено как данные API ГрГУ, а оценки, задания и сессия — как демо. Сохранённые экраны содержат заданные примеры; рабочее подключение к API или модели ассистента этим экспортом не подтверждено.
