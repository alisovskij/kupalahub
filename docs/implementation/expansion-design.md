# Расширение дизайна A «Ясный день»

22.11.2026. Десктопное веб-приложение, без ИИ. Основание: выбранный A, текущий интерфейс и `docs/grsu-data-catalog.md`. Пользователь просит расширить функциональность и сохранить понятность. Настоящий документ — контракт для реализации, а не подтверждение новых источников данных.

## Дизайн-направление

Спокойное рабочее пространство для ежедневной учёбы. Первым читается ближайшее действие, вторым — его срок и источник. Сохраняем фон #F3F5F8, белые поверхности, текст #233249, действие #3159C7; янтарный только для изменения/срока, зелёный для положительного результата. Onest локально, основной текст 15px, вспомогательный 13px, страницы 30–32px, блоки 19px. Числа не должны заменять смысл статуса.

Sidebar 226–232px, контент с полями 32–42px. Основные границы — отступы и тонкие разделители. Таблицы не раскладывать в сетку маленьких карточек. Правый контекст 280–320px использовать лишь там, где он помогает решить задачу.

## Навигация

Постоянные верхние пункты: Сегодня, Расписание, Задачи. Остальные сгруппированы в небольшие разделы:

- **Учёба:** Успеваемость (Оценки / Аттестация / Пропуски), Материалы, Сессия.
- **Университет:** Преподаватели, Кампус, Группа.
- **Личное:** Платежи и документы (Оплата / Поступления / Приказы), Профиль и настройки.

Группы могут быть раскрывающимися; активная группа раскрыта. При 900px высоты прокручивается область навигации, профиль остаётся внизу. Не размещать четырнадцать одинаково заметных ссылок. Уведомления доступны иконкой с подписью и отдельным списком, а не тревожным баннером на каждом экране. На Today оставить текущую композицию: повестка и задачи.

## Общий контракт данных

Каждый экран: заголовок, короткое назначение, локальный статус источника и основное действие. Метаданные `source`, `fetchedAt`, `stale`, `status`, `coverage` переводятся в понятную подпись. Различать:

1. **Реальные:** «API ГрГУ · обновлено 12:10».
2. **Собственные:** «Введено в Kupala Hub» или «Моя группа в Kupala Hub».
3. **Пример:** постоянный бейдж «Демо» и строка «Пример данных, не сведения твоего аккаунта».
4. **Не подключено:** статус текстом, без таблицы выдуманных нулей. Действия: «Посмотреть пример», «Открыть портал». Не предлагать рабочую кнопку синхронизации там, где интеграции нет.

Демо включается явным действием и не перемешивается с живой страницей. Глобальный демо-режим наследуется; локальное демо чтения закрытого раздела не меняет реальные задачи пользователя. Формулировка «Подключить» допустима только если действие действительно реализовано.

## Экраны

| Экран | Композиция и главное действие | Ограничения |
| --- | --- | --- |
| Успеваемость | Вкладки, выбор семестра; таблица «Дисциплина / Контроль / Результат / Период». Детали по строке справа или в диалоге | Не показывать официальный рейтинг/средний балл без основания. «Нет данных» отличается от «не сдано» |
| Аттестация | Та же оболочка, компактные строки предметов и результата за выбранный период | Не вычислять официальный допуск |
| Пропуски | Таблица «Дата / Количество / Причина». Фильтр периода, подробности при наличии | Не подписывать количество «часами», пока единица не подтверждена |
| Материалы | Две вкладки «Мои материалы / Портал». Свои: список заметок/ссылок с дисциплиной и поиском; портал: disconnected/demo | Ссылки открывать безопасно; не обещать загрузку файлов, если нет хранилища |
| Сессия | Список событий по датам, фильтры Экзамен / Зачёт / Консультация / Защита; строка со временем, местом и предметом | Источник — расписание. «Опубликованных событий не найдено», без утверждения, что сессии нет |
| Преподаватели | Поиск сверху; список имён и должностей, выбранный профиль и его неделя справа. Email как письмо только при наличии | Не «где находится», а «по расписанию». Контакты могут отсутствовать |
| Кампус | Список адресов из текущего покрытия, фильтры даты и времени. Результат: «Занятия не найдены в доступных расписаниях» | Явно указать группу/период покрытия. Не рисовать зелёный статус «точно свободно» |
| Группа | Заголовок пространства и членство; вкладки Объявления / Задания / Участники. Публикация модальной формой | Внутреннее членство не равно официальному. Роль «администратор пространства», не автоматически «староста университета» |
| Оплата | Таблица записей/сроков только при разрешённом источнике либо демо | Поступление средств не называть стипендией. Не добавлять проведение платежей |
| Приказы | Список названий, деталей/ссылок если доступны, источник у записи | Не придумывать номера реальных приказов. Нет источника — disconnected |
| Профиль | Имя и email аккаунта; учебная группа/подгруппы отдельным блоком; настройки с кнопкой сохранения | Университетский профиль отдельный disconnected блок. Не использовать выбранную группу как доказательство личности |
| Уведомления | Список изменений, разделы Новые/Все, дата обнаружения и переход к паре | История только с момента наблюдения, не гарантированная доставка push |

## Состояния и действия

- Loading: skeleton по форме будущего списка, `role=status`, не менять высоту заголовка.
- Empty: назвать отсутствие результата/записей и дать действие создать/изменить период. Нули допустимы только для действительно вычисленного пустого набора.
- Error: конкретная ошибка и повтор; сохранённые данные остаются с предупреждением.
- Partial: показать охват и отсутствующие поля «не указано»; не скрывать всю таблицу из-за пустого телефона.
- Success: короткий toast, повторное открытие показывает сохранение. Деструктивные действия — отдельное подтверждение.
- Permission: объяснить, какое действие требует членства/роли; состояние чтения остаётся доступным, если допускает контракт.

Первичные кнопки только для наиболее частого действия. Тихие ссылки для смены периода/просмотра деталей. Иконки имеют `aria-label`; важные действия не появляются только по hover. Диалоги возвращают фокус. Таблица имеет `caption`/заголовки, формы явные labels. Цвет всегда дополняется словом. Фокус 3px, reduced-motion, контраст текста проверять отдельно.

## Визуальные цели приёмки

Desktop 1440×1000 и 1280×900. Первое окно объясняет раздел и источник без чтения справки. Длинные ФИО/предметы переносятся; контакты не выталкивают действия. Страница без горизонтального переполнения, широкая таблица прокручивается в своём контейнере. Навигация не занимает больше трети ширины. Минимальный полезный текст 13px; отсутствие данных не превращает экран в декоративный dashboard.

`design/expansion/preview.html` демонстрирует направление: четыре страницы, состояния disconnected/demo и общий ритм. Это композиционный прототип, не подключённые рабочие данные. Браузерная приёмка реализации поручается отдельному тестеру; наличие этого документа не означает её прохождение.
