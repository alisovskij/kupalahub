# Проверка первой рабочей версии

Дата: 16.11.2026. Область: десктоп, без ИИ.

## Сервер

10 предметных/API-тестов (`node tests/api.test.js`) прошли. `npm test` также проходит; в этой среде стандартный репортёр Node группирует файл как один результат. Сборка Vite прошла. Чистая установка `npm ci` проверена в отдельном каталоге; пакет нативного Rollup загружается. Lock-файл включает платформенные optional-зависимости. Проводилась на Node 26.13.1; минимальная Node 22.13 отдельно не запускалась.

Проверены: календарь Минска и границы времени; подгруппы и перекрытия; валидация ответов; CSRF и запрет cross-site записи; принадлежность задач; изоляция live/demo; регистрация гостя и смена сессии; вход/выход; сохранность SQLite после перезапуска; недоступность API; выдача старого снимка и защита от массовых отмен при подозрительно пустом ответе.

## Браузер

Виртуальный Playwright, пользовательский Chrome не запускался. Сборка React загружена из `dist/`. В среде запрещено открытие TCP-портов: запросы браузера передавались реальному Fastify через `app.inject()` с сохранением HTTP-статусов, cookie и CSRF. Данные ГрГУ получены действительными публичными запросами и переданы адаптеру как зафиксированные ответы. Прямой TCP-сценарий браузер → локальный порт не проверен в этой среде.

Выполнены: выбор реальной группы ФМИ → загрузка расписания → создание задачи → завершение → перезагрузка → проверка сохранения → регистрация с переносом гостевых задач → выбор подгруппы (5 записей дня сократились до 3) → недельный вид из 7 дней → редактирование задачи → экспорт ICS → выход в новый гостевой профиль без задач аккаунта. В этих действиях pageerror отсутствовал. Контролируемый checkbox обновляется после ответа сервера; автоматическое `check()` не ждало сетевой мост, поэтому результат дополнительно проверен после ответа.

## Ограничения проверки

Независимые агенты ревью были запущены, но завершились из-за лимита сервиса и заключений не дали. Независимый code review и автоматический ESLint/a11y-аудит не выполнены. Полная WCAG-сертификация, нагрузочные тесты, почтовые сценарии, offline-PWA и мобильная версия не заявляются.

Дизайн: сохранены спокойный фон, белая повестка, синий акцент, боковая навигация и задачи справа. Данные помечаются источником; пустые дни не объявляются гарантированными выходными. Формы подписаны, dialog использует нативный фокус и Escape; есть видимый фокус, skip-link и reduced-motion. Полная проверка всех состояний по чек-листу дизайн-навыка ещё не завершена, прохождение такого чекера не заявляется.
