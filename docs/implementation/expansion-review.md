## Проверки безопасности и поведения

- SQL параметризован; материалы и профиль ограничены владельцем.
- Членство в сообществах проверяется по user_id и scope; организатор публикует и управляет общими заданиями, участник голосует.
- Код приглашения не выдаётся обычному участнику; его ротация и отзыв членства учтены.
- Голосование проверяет опрос, выбранный вариант и членство; повтор заменяет голос, а не создаёт второй.
- Изменяющие API наследуют проверку session/CSRF/origin; чтение локальных данных дополнительно требует своей сессии.
- Демо и закрытые неподключённые источники обозначены явно; live-ошибка не подменяется вымышленным ответом.
- Публичные данные преподавателей используют общий кэш и ограниченную очередь запросов. Не выполняется массовый обход аудиторий/групп.
- React выводит пользовательские тексты как текст; личные материалы принимают HTTPS-ссылки без credentials. HTML не вставляется через dangerouslySetInnerHTML.
- Данные запросов useResource очищаются/отменяются при смене страницы; ключ новой страницы включает page, scope и сессионный CSRF, чтобы не сохранять локальное состояние другого аккаунта.
- Напоминания описаны как внутриприложенческий список, а не гарантированные push при закрытом браузере.
