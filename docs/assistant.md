# Учебный ассистент

Основной API остаётся на JavaScript/Fastify. Отдельный Python/FastAPI-сервис обращается к модели `deepseek-flash` через прокси `https://llm.azati.ai`, как в `project-matcher`, и вызывает ограниченные инструменты основного API. Браузер обращается только к Fastify; ключ прокси в клиентскую сборку не попадает.

## Локальный запуск

Нужны Node.js 22.13+, Python 3.12+ и зависимости проекта. Из корня:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r ai_service/requirements.txt
npm run setup:agent
```

В `.env` заполните `DEEPSEEK_API_KEY` ключом прокси с доступом к flash. В `project-matcher` такой ключ выбирается как `DEEPSEEK_API_KEY_THINKING`; здесь для единственной модели оставлено одно имя — `DEEPSEEK_API_KEY`. Переносить все настройки или секреты из другого проекта не нужно. Настройка создаёт случайный `AGENT_SERVICE_TOKEN` для связи двух сервисов; заполненные ключи сохраняются. Один и тот же сервисный токен нужен обоим сервисам. Файл исключён из Git и Docker-контекста.

```bash
npm run dev
```

Команда читает `.env`, запускает JavaScript API, Vite и Python из `.venv`. Открыть http://localhost:5173 → «Ассистент». Без ключа страница сообщает о недоступности, остальные разделы работают. После добавления ключа перезапустите процессы и обновите страницу.

Для собранной версии запустите в двух терминалах `npm start` и `npm run start:agent`, предварительно выполнив `npm run build`. Открыть http://localhost:3001. Обе команды читают `.env`. `PYTHON_BIN` позволяет указать другой исполняемый файл Python.

## Docker

После настройки `.env`:

```bash
docker compose up --build -d
```

Два отдельных контейнера, Python-порт наружу не опубликован. Приложение доступно на http://localhost:3001; SQLite хранится в именованном томе `kupala-data`. Этот том отделён от локального каталога `data/`: данные автоматически между ними не переносятся. При размещении за HTTPS задайте собственный `APP_ORIGIN` и `COOKIE_SECURE=true`. Docker-сборка в текущей среде не выполнялась.

## Чем помогает

- Составляет план дня по занятиям, свободным промежуткам и задачам.
- Показывает ближайшие сроки в доступной выборке задач, помогает расставить приоритеты.
- Разбивает большой проект на конкретные задачи и предлагает даты работы.
- Ищет по названиям и тексту личных материалов, помогает разобрать предоставленный текст.
- Предлагает создать, перенести, уточнить или завершить задачу. Карточка показывает результат; только кнопка подтверждения применяет его. Предложение действует 10 минут. Если задача уже изменена вручную, требуется новое предложение.

Примеры: «Спланируй завтра, оставь час на подготовку к лабораторной», «Разбей курсовую на пять задач», «Перенеси работу над отчётом на пятницу, срок сдачи оставь прежним».

Контекст формируется заново при каждом сообщении: текущее время Минска, имя и выбранная группа, до 40 задач, до 8 заметок и текущая неделя расписания. Большие записи сокращаются с отметкой ограничения. Инструмент расписания позволяет запросить другую неделю в пределах шести недель от текущей даты; поиск материалов просматривает последние 100 записей. Содержимое внешних ссылок не скачивается. История изолирована по пользователю и live/demo: хранится до 40 сообщений, в модель передаются последние 12.

Перед отправкой требуется включить передачу контекста. Снятие галочки блокирует последующие отправки; уже переданный провайдеру запрос этим не отзывается. Корзина удаляет историю и предложения из приложения, но не отзывает данные, уже переданные DeepSeek. Закрытые данные портала, оценки, сведения о студентах и официальные полномочия старосты ассистенту недоступны. Демонстрационные данные помечены как примеры.

## Настройки и ограничения

- `DEEPSEEK_API_KEY` — ключ прокси с доступом к flash, только на Python-сервисе при раздельном размещении.
- `DEEPSEEK_BASE_URL` — по умолчанию `https://llm.azati.ai`. Модель фиксирована: `deepseek-flash`, переключателей режимов нет. Обычно адрес менять не требуется.
- `AGENT_SERVICE_TOKEN` — общий секрет двух сервисов, минимум 32 символа.
- `AI_SERVICE_URL` — адрес Python для Fastify, локально `http://127.0.0.1:8001`.
- `KUPALA_BACKEND_URL` — адрес Fastify для Python, локально `http://127.0.0.1:3001`.

Для межсервисной связи разрешён HTTP только для loopback и имён контейнеров `ai`/`backend` соответственно; удалённые адреса требуют HTTPS. Адрес LLM-прокси также требует HTTPS, кроме локальной разработки через loopback. Доступ к инструментам дополнительно требует подписанного разрешения на конкретного пользователя, пространство и активный запрос. Python не получает доступ к SQLite.

Подключение повторяет существенные правила клиента `project-matcher`: запрос Chat Completions, авторизация Bearer, отсутствие неподдерживаемого параметра `thinking`. Flash на этом прокси считается моделью с рассуждением; поэтому выбор инструментов передаётся через проверяемый JSON-ответ, без нативных `tools`/`tool_choice`. Модель запрашивает разрешённый инструмент, сервис валидирует аргументы и возвращает результат; права доступа и подтверждение изменений остаются в JavaScript API. Для базового адреса с `/v1` используется `/v1/chat/completions`, с `/debug` — сам `/debug`, как в клиенте проекта-образца.

Один запрос пользователя выполняет максимум 4 обращения к модели и 8 вызовов инструментов, не более 2000 выходных токенов на обращение. Одновременно допускаются 4 чата на Python-процесс; Fastify ограничивает пользователя 30 сообщениями в час и одним активным чатом на пространство. На ответ Python отведено 70 секунд. Это ограничения нагрузки, а не денежный бюджет аккаунта DeepSeek. Автономных фоновых действий и напоминаний нет.

## Проверка

```bash
npm test
npm run test:agent
npm run build
```

Добавлены 7 проверок Node: изоляция контекста и истории, согласие, разрешения инструментов, подтверждение действий, конфликты и срок действия, сбои, размер контекста. Python проверяется с подменой HTTP-провайдера, без оплаты запросов. Реальный ответ DeepSeek требует вашего ключа и отдельно не проверен. Автоматическая браузерная приёмка нового экрана не выполнялась из-за ограничений виртуального браузера среды.
