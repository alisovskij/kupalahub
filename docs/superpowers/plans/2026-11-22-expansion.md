# Расширение Kupala Hub

Пользователь поручил добавить функции каталога и использовать отдельных агентов. Основное направление дизайна A сохраняется. Desktop-only, JavaScript на сервере, без ИИ. Источники с закрытым доступом не подменяются демонстрацией: состояние подключения отделено от просмотра примера. Проверка SSO приостановлена.

## Задачи и ответственность

1. Архитектор: уточнить API/данные/границы в `docs/implementation/expansion-plan.md`.
2. Дизайнер: композиция и навигация, `docs/implementation/expansion-design.md`, самостоятельный визуальный preview.
3. Бэкенд: `server/expansion.js`, `server/expansion-demo.js`, `tests/expansion.test.js`. Закрытые категории в demo/disconnected, профиль, настройки, материалы-ссылки, сообщества с приглашениями, роли и голосования, покрытие кампуса по одной группе.
4. Публичные источники: справочник преподавателей и их расписание через общий ограниченный адаптер ГрГУ, сессия по опубликованным занятиям, тесты.
5. Фронтенд: модульные новые страницы и интеграция в оболочку A; без потери существующих расписания, задач и аккаунтов.
6. Проверяющий: владельцы данных, CSRF, участие/роли сообщества, разделение demo/live, валидность источников, React-состояния.
7. Тестер интерфейса: основные переходы и формы на 1440/1280 desktop в виртуальном браузере; снимки и фактические ограничения проверки.
8. Интеграция: сборка, серверные тесты, документация, итоговый список реализованного/условного.

## Критерии

- Существующие данные SQLite сохраняются, схемы расширяются аддитивно.
- Закрытая интеграция не запрашивает пароль университета и не выглядит подключённой.
- Реальные данные и собственные записи отделены от демо в API/БД/UI.
- Кнопки либо выполняют действие, либо ясно описывают недоступность; нет имитации синхронизации.
- Преподаватели и сессия имеют источник/дату и ошибочное/пустое состояние.
- Кампус не обещает фактическую свободу помещений и показывает покрытие выбранной группы.
- Чужая сессия не читает материалы/профиль/закрытые сообщества; участник не получает права организатора через выбор учебной группы.
- Сборка и поведенческие тесты проходят; страницы проверены браузером. Если нельзя открыть локальный порт — проверка через Fastify inject и перехват HTTP виртуальным браузером с явным указанием ограничения.
